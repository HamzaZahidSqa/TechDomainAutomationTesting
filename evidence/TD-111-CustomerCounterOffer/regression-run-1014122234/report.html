What was tested (in plain words)

A customer creates a work order and submits it to Tech Domain. Tech Domain opens it and can send a Counter Offer with different rates and extra expenses. The customer sees it under a new Proposals tab and can Accept or Decline. If accepted, the work order carries on with the accepted rates and expenses, and every later amount (Payment tab, estimated payment, completion totals) is calculated from them. Tech Domain can also Edit or Withdraw a pending counter offer. When several Tech Domain users send counter offers, the latest one replaces the earlier one and the customer only answers the latest; after acceptance nobody can counter any more. All actions were performed through the web UI with a screenshot per step; the API was used only to create the test work orders, to move the engineer through the job and to read back the calculated amounts.
